# Side effects and operational limits

The companion creates an Electron process and a floating window, consuming memory,
CPU/GPU time, and desktop space. It listens on loopback port `17837` by default;
a conflicting service can prevent startup. Hooks, metadata checks, and local
source observation add some process and I/O overhead.

Explicitly authorized independent estimation sends readable task context to the
selected provider. Compression and synthetic trials can add requests. Review the
recipient and usage notice; hiding the window does not stop already authorized
estimation. Provider outages, unknown usage, stale results, and context limitations
remain visible operational outcomes.

The plugin page controls global plugin enablement. Window visibility and per-task
tracking controls are separate. They do not pause, resume, cancel, or control the
underlying Codex task. Successful completion of a final response does not prove a
correct repair. A silence interval or lost lease cannot establish task success.

Use the [source installation guide](INSTALL-WINDOWS.md) for the actual distribution
path and matching runtime requirements. Read [known limitations](KNOWN-LIMITATIONS.md)
for accuracy and compatibility, and [privacy](../PRIVACY.md) for content, account,
retention, and cost details. Treat model uncertainty as a stated estimate, not a
calibrated coverage guarantee.
