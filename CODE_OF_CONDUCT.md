# Code of Conduct

We want participation in this project to be safe, respectful, and constructive.

Be considerate, criticize ideas rather than people, respect differing experience levels, and avoid harassment, discrimination, threats, sexualized attention, doxxing, or publication of another person's private project data. Maintainers may edit or remove contributions and restrict participation when behavior harms the community.

Report conduct concerns through the repository's private security or maintainer contact channel. Reports will be handled as confidentially as practical. Good-faith reports and disagreements about technical decisions must not lead to retaliation.

This code applies in project repositories, discussions, issue trackers, review channels, and public spaces where someone represents the project.
